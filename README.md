# 🐣 Bichitos

Virtual pet game for Android. Hatch an egg and raise your own digital pet!

## Features

- 🥚 Egg incubation (rub to speed up!)
- Offline save with SharedPreferences
- Stats: Happiness, Hunger, Care & Neglect

## Tech

Java · Android SDK · SharedPreferences · Gson
